# 东京“值得和朋友一起去”发现服务：竞品与研究报告

**研究日期：** 2026-08-27  
**研究范围：** 东京活动与地点发现服务、日本本地生活媒体、海外朋友共同决策产品，以及推荐系统、共同体验、偶遇感与空间氛围相关研究。  
**方法限制：** 本报告是公开资料桌面研究，不包含用户访谈、实际产品留存数据或商户访谈；平台规模数据若无第三方审计，均按平台自述处理。

## 一、结论摘要

东京不缺活动数据库，也不缺城市指南。真正稀缺的是一种同时满足以下条件的服务：

1. 面向在东京生活的人，而不是主要服务一次性游客；
2. 同时收录限时活动、周期活动、大学开放、新店、即将消失的店和长期存在但刚被发现的场所；
3. 不以“美食／艺术／运动”作为第一层导航，而以“为什么现在值得去”组织内容；
4. 有明确、可解释的编辑判断：它必须足够好，或者足够独特；
5. 产品目标不是让用户继续浏览，而是让用户把一张卡片发给朋友并促成出门。

现有服务分别拥有其中一部分：Time Out Tokyo 有城市编辑能力，Tokyo Art Beat 有艺术垂直深度，开店闭店类媒体有生命周期信号，The Nudge 擅长把推荐变成可执行计划，Cobble 和 DICE 处理朋友共同决策，Beli 利用朋友的品味建立信任。但暂未发现一个在东京把这些能力完整组合起来的主流服务。

因此，最有潜力的定位不是“东京活动聚合器”，而是：

> **一个有判断力的东京现实生活编辑部：持续发现城市里正在出现、正在发生和正在消失的好东西，并让用户容易约朋友一起去。**

| [开店闭店.com](https://kaiten-heiten.com/) | 全国开业／闭店情报聚合 | “刚出现”和“即将消失”的信号直接，适合作为线索池 | 信息量大但没有品味筛选；开业或闭店本身不代表值得去 |
| [号外NET](https://goguynet.jp/) | 区级本地新闻、居民投稿、开闭店与活动 | 颗粒度细，能发现大型媒体忽略的社区变化；官方称每月收到 2,500 条以上信息投稿 | 各区质量不一，信息分散；适合发现线索，不适合直接展示全部内容 |
| [Atlas Obscura 东京](https://www.atlasobscura.com/things-to-do/tokyo-japan) | 世界范围的奇异地点数据库 | 以隐藏、奇怪、意外为明确筛选标准，东京页已有大量长期地点 | 偏游客与常青地点；更新时间、闭店状态和东京本地日常语境可能不足 |
| 大学官网与研究机构页面 | 开放日、校园导览、公开讲座、实验室与设施开放 | 内容独特、可信，普通活动平台经常覆盖不足；如[东京大学校园导览](https://campustour.pr.u-tokyo.ac.jp/schedule/list)和[柏校区一般开放](https://www.kashiwa.u-tokyo.ac.jp/contact/) | 来源高度碎片化，命名和发布时间不统一，需要单独建立监测网络 |

### 判断

日本市场的主要缺口不是“缺少信息”，而是信息被分割在官方页面、售票平台、区级媒体、大学官网、Instagram 和店铺公告中。大型服务擅长库存、搜索或流量变现，小型媒体擅长某个街区或主题，但缺少跨来源、跨生命周期的强编辑层。

最接近本项目的不是某一个竞品，而是一种组合：

> **The Nudge 的行动型编辑 + Tokyo Art Beat 的垂直资料质量 + 开闭店媒体的时间信号 + DICE/Cobble 的朋友决策 + Beli 的熟人信任。**

## 四、相关研究及产品含义

### 1. “和朋友一起”不是包装，而是体验价值本身

Boothby、Clark 与 Bargh 的两项实验发现，即使共同体验者没有交谈，仅仅同步经历同一件事，也会放大体验强度；愉快体验会更愉快，不愉快体验也会更不愉快。后续研究进一步发现，这种放大效应受到心理距离调节，与熟悉、亲近的人共同体验时更明显。([2014 论文](https://acmelab.yale.edu/sites/default/files/2014_shared_experiences_are_amplified.pdf)，[2016 论文](https://clarkrelationshiplab.yale.edu/sites/default/files/files/BoothbySmithClarkBargh.pdf))

Caprariello 与 Reis 的研究则指出，消费带来的幸福优势更关键的变量不是“物品还是体验”，而是它是否具有社会性；人们更偏好社会性而非独处型的自主消费。([论文摘要与 DOI](https://pubmed.ncbi.nlm.nih.gov/23276272/))

**产品含义：** 第一目标应是帮助已有朋友共同出门，陌生人搭伴可作为第二层。每张卡片都要说明“适合和怎样的朋友去”，分享和共同决定应是核心功能，而不是页面末尾的附加按钮。

### 2. “独特”可以被拆成可操作维度

Lee 与 Crompton 对旅游新奇性的经典量表把 novelty 拆成四部分：刺激、日常变化、解除无聊和惊喜。([研究](https://www.sciencedirect.com/science/article/pii/016073839290064V)) 后续研究也把新奇性视为愉悦和难忘体验的重要机制，但新奇并非越高越好，感官氛围、正向情绪与个体差异同样重要。([2018 研究](https://www.sciencedirect.com/science/article/pii/S0160738318300690)，[2022 综述](https://doi.org/10.1002/mar.21665))

**产品含义：** “独特分”不能只是编辑凭感觉打出的怪异度。至少应分别记录：是否改变日常、是否带来惊喜、是否提供新的参与方式、是否只有东京或此时此地才成立。

### 3. 偶遇感不是随机，而是“意外 + 有用 + 相关”

推荐系统中的 serendipity 通常不是纯随机。综述研究指出，有价值的偶遇推荐需要同时具备相关性、新颖性和相对用户既有兴趣的意外性；只推荐相似内容会让用户感到无聊，但完全无关的怪东西也不构成好的偶遇。([Kotkov 等，2016](https://www.sciencedirect.com/science/article/pii/S0950705116302763))

**产品含义：** 首页应保留少量“你没搜过但有理由喜欢”的内容，并明确解释推荐桥梁，例如：“你喜欢建筑，但可能没想到大学风洞实验室会开放。”可解释性比黑箱相似度更适合早期产品。

### 4. 选项越多，不一定越容易出门

旅游决策研究通过五项研究验证了选择过载：目的地选项过多会增加不确定性，降低选择后的评价；提高决策信心可以缓解这一问题。([研究](https://www.sciencedirect.com/science/article/pii/S0160738316301669))

**产品含义：** 不应建设无限滚动的活动海洋。每周 8–15 个强推荐，比 500 条完整列表更符合产品目标。每条都要给出明确的选择理由、时间成本和适合对象，帮助用户有信心转发和拍板。

### 5. 朋友共同推荐不能只取平均偏好

群体推荐研究总结了平均、多数、最大满意和“最少痛苦”等聚合策略。不同策略会导致不同群体结果，单纯平均可能让每个人都觉得一般。([2023/2024 开放综述](https://link.springer.com/article/10.1007/s11257-023-09380-z)) 事件型社交网络研究还强调，线下活动推荐同时受线上关系、线下关系、时间、地点和隐性反馈影响。([AAAI 2014](https://ojs.aaai.org/index.php/AAAI/article/view/9095))

**产品含义：** 两人共同选择时，可以先排除任何一方明确不接受的价格、距离、语言或社交强度，再在剩余项中寻找“至少有一个人非常兴奋”的选项，而不是只找两个人评分都为 6 分的安全答案。

### 6. 特殊氛围的店铺，需要评价空间本身

Bitner 的 servicescape 框架指出，物理环境会影响顾客和员工的认知、情绪与行为，空间不只是服务的背景。([论文](https://doi.org/10.1177/002224299205600205)) 关于公共空间与社会凝聚力的系统综述也显示，公共或半公共“第三空间”能够承载偶遇、社会关系、地方依恋与社区感，但效果取决于空间和情境条件。([2024 系统综述](https://doi.org/10.1007/s42413-024-00204-5))

**产品含义：** 有氛围的店不能只用“装修好看”判断。应记录声音、光线、密度、停留规则、人与人的互动方式、老板或店员的角色，以及空间是否允许朋友舒服地共同待一段时间。

## 五、建议建立的分类与数据结构

### 第一层：为什么现在去

- **刚刚开门：** 正式开业 90 天内，仍处于探索期；
- **趁它还在：** 已由店铺、业主、机构或可靠媒体明确确认闭店、搬迁、拆除或长期休止；
- **限时发生：** 有明确开始与结束日期的展览、开放、快闪或体验；
- **定期回来：** 每周、每月、每季或每年重复，可预测下一次；
- **最近发现：** 并非新开，但刚被编辑验证，且在目标用户的信息圈中覆盖较少；
- **东京新玩法：** 新奇运动、手作、城市探索或难以归类的消遣方式。

### 第二层：它是什么

店铺、艺术与展览、大学与校园、建筑与空间、运动与户外、音乐与夜生活、吃喝、手作与学习、城市奇观。

### 每条记录应增加的核心字段

| 字段 | 作用 |
|---|---|
| `why_now` | 刚开、将消失、限时、周期、最近发现或新玩法 |
| `object_type` | 店铺、展览、校园、运动等内容类型 |
| `quality_score` | 完成度、内容、服务与实际体验质量 |
| `uniqueness_score` | 稀缺性、东京性、反常性和不可替代程度 |
| `evidence` | 支撑“好或独特”的具体事实，不使用空泛形容词 |
| `friend_fit` | 适合哪类朋友、社交强度、是否适合两人或多人 |
| `best_moment` | 最佳日期、时段、天气与拥挤规避建议 |
| `friction` | 预约、价格、距离、语言、着装和现场规则 |
| `after_plan` | 去完后可自然衔接的散步、吃饭或喝酒方案 |
| `verified_at` | 最后人工或自动核实时间 |
| `source_tier` | 官方、可靠媒体、社区线索或用户投稿 |

### 收录门槛

建议采用双门槛而非平均分：

- `质量 ≥ 8`，或者 `独特性 ≥ 8`；
- 另一项不得低于 5；
- 信息真实性、安全性和可访问性必须合格；
- 编辑必须能够用一句具体事实解释“为什么值得去”。

这样可以容纳“并不精致但极其独特”的地方，也能容纳“并不猎奇但好到值得专程去”的体验，同时拒绝既普通又一般的活动。

## 六、推荐的内容供应链

1. **广泛抓取候选：** 官方活动日历、博物馆与画廊、大学新闻与一般开放、区级媒体、店铺官网和许可范围内的公开社交账号；
2. **识别生命周期：** 抽取开业日、闭店日、展期、周期规则和预约截止时间；
3. **可信度分层：** 官方公告优先，可靠媒体次之，社区投稿只作为待核实线索；
4. **自动初筛：** 排除招聘、促销、普通说明会、长期景点和重复内容；
5. **人工编辑判断：** 只判断“好或独特”的证据，不替活动方改写广告；
6. **发布后复核：** 临近日期再次检查营业状态、余票、天气影响和闭店信息；
7. **事后反馈：** 不只问五星评分，而是问“是否值得专程去”“会不会推荐给朋友”“现场与描述是否一致”。

## 七、差异化与护城河

### 真正的差异化

- **以时间理由而非内容门类组织城市；**
- **把事件和地点放进同一个生命周期系统；**
- **内容数量少，但每条都提供可验证的编辑判断；**
- **围绕朋友转发、共同排除和拍板设计，而非围绕浏览时长；**
- **长期记录城市变化：何时开、何时被发现、何时消失。**

### 真正的护城河

爬虫不是护城河。长期价值来自：

1. 哪些碎片化来源值得持续监测的知识网络；
2. 一套稳定、可审计的“好或独特”编辑标准；
3. 到访后的真实反馈数据；
4. 用户把什么内容发给哪类朋友，以及最终是否成行的决策数据；
5. 对东京小型空间、大学和亚文化场景逐渐形成的关系与信任。

## 八、主要风险

- **闭店误报：** “快倒闭”只能基于正式公告，不根据客流、传闻或经营状况推测；栏目名称建议使用“趁它还在”或“即将告别”。
- **小店被流量伤害：** 对容量极小、居民敏感或明确不希望曝光的地方，应征得许可、模糊定位或不收录。
- **商业内容污染：** 商户可以投稿或购买明确标注的展示位，但不能购买编辑评分或“独特”结论。
- **新奇偏见：** 独特不等于优质；必须诚实披露粗糙、语言门槛、排队和体验不稳定等问题。
- **抓取合规：** 遵守 robots.txt、站点条款与合理频率，只保存事实摘要并链接回原始来源；优先使用官方开放页面、RSS、API 或获得授权的数据。
- **信息衰减：** 店铺和活动状态变化快，所有卡片都必须显示最后核实时间并设置自动过期。

## 九、建议的验证顺序

在继续扩建抓取器前，先验证编辑判断是否真的能促成朋友出门：

1. 连续四周，每周人工精选 10 条；
2. 找 15–20 位在东京生活的用户，每周记录他们转发、收藏、讨论和实际成行情况；
3. 对比三种文案：事实型、编辑理由型、朋友邀请型；
4. 重点指标不是点击率，而是“发送给朋友率”“形成共同收藏率”“确定日期率”和“实际到访率”；
5. 根据到访反馈修正质量分、独特分和朋友适配标签，再决定个性化算法。

## 十、最终判断

市场已经证明人们需要活动数据库、垂直指南、开闭店情报和朋友协作工具，但这些能力仍然彼此分离。这个项目最值得做的，不是另一个覆盖更多活动的网站，而是一个覆盖更少、判断更强、能让人真正约朋友出门的城市发现产品。

一句话版本：

> **东京不缺事情，缺的是有人替你判断：哪一件值得现在叫上朋友一起去。**
