## 已知的坑

**早稲田大学 403。** `https://www.waseda.jp/robots.txt` 返回 403 而非 200/404，
`assertRobotsAllowed` 按"非 2xx 即抛错"处理，来源整体失败。这是策略选择的结果不是 bug：
拿不到 robots 就不抓。要恢复这个来源，得先弄清 403 是针对默认 UA 的拦截还是站点配置，
不能简单地把 403 当 404 放行。

**Big Sight 的公开性判定太粗。** `isPubliclyAccessible()` 只看 `audience` 是否含「一般」。
方案 §5.2 写了五条保留条件（能否合法报名、是否要求虚构身份、现场有无实体展示等），
现在一条都没实现，结果是模型展、机器人展这类"商谈但值得去"的内容一律被打进待审。

**没有"条数异常下降"告警。** 某来源改版后解析出 0 条，管线只会当成今天没活动。
上表的 `原始条数` 就是给人工对照用的基线。

## 加一个来源要做的事

1. 先看 `robots.txt` 与使用条款。
2. 在 `scripts/sources/` 建 `<来源>.mjs`，导出 `parse<来源>(html, source)` 和 URL 常量；
   用 `createEventCandidate()` 造记录。
3. 同目录建 `<来源>.test.mjs`，**用内联 HTML 夹具**，不要打网络。
4. 注册进 `scripts/sources/index.mjs`。
5. 跑一次 `npm run update-events`，把原始条数补进上面的表。
6. **不要新建 `index-v2.mjs`。** 见 `决策记录/0001-收敛版本树.md`。
